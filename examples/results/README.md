# Реальные результаты генерации

Сюда скрипт `scripts/run_submission_check.py` сохраняет JSON-ответ, Markdown-версию и общий отчёт после реальных вызовов локального API/Ollama.

Не добавляйте сюда вручную придуманные карточки или выводы, не полученные от запущенного приложения. Для полного выполнения тестового задания нужны результаты двух реальных товаров из исходных материалов работодателя. Синтетический TP-200 для этого не подходит.
