# Реальные результаты генерации

Сюда скрипт `scripts/run_submission_check.py` сохраняет JSON-ответы, Markdown-версии и общий отчёт после реальных вызовов локального Product Copy AI API/Ollama.

Для тестового задания используются два товара из каталога СОЮЗ-ПРИБОР:
- ОВЕН ДТС024-100П.В3.30/1;
- ОВЕН ПД100-ДИ4,0-185-0,5.

Перед запуском проверь, что обе позиции присутствуют в XML-фиде работодателя. Источники и спорные характеристики описаны в `docs/PRODUCT_SOURCES.md`.

Не добавляйте вручную придуманные карточки или выводы, не полученные от запущенного приложения. После генерации проверьте каждый факт по исходной карточке/паспорту и разберите все предупреждения. Результат со статусом `needs_review` не следует представлять как готовый к публикации.
