# Источник данных: ОВЕН ПД100И

**Статус:** внешний демонстрационный пример для проверки второго сценария Product Copy AI. Это не второй товар, приложенный работодателем к тестовому заданию.

**Первичный источник:** [Руководство по эксплуатации ОВЕН ПД100И](https://docs.owen.ru/product/pd100i/176), документ 1-RU-18907-1.33.

## Как выбрана конфигурация для демонстрационного JSON

В JSON используется серия ПД100И, тип измеряемого давления ДИ (избыточное), модель 1Х1 и диапазон 0–1,6 МПа. Руководство допускает для модели 1ХХ тип ДИ с верхним пределом 1,6 МПа и нижним пределом 0 МПа. В таблице технических характеристик модель 1Х1 поддерживает тип ДИ.

Из руководства также взяты:
- аналоговый выходной сигнал 4–20 мА;
- питание модели 1Х1 постоянным током 10–40 В, номинально 24 В;
- материал мембраны для модели 1Х1 — сталь AISI 316L;
- электрический соединитель DIN 43650 A;
- степень защиты корпуса IP65;
- перегрузочная способность не менее 200 % диапазона измерения;
- назначение: измерение и преобразование давления, участие в регулировании технологических процессов в системах автоматического контроля.

## Что намеренно не указано

Полное заказное обозначение, конкретное присоединение к процессу и индивидуальное значение допускаемой основной погрешности не добавлялись. Руководство указывает, что способ присоединения выбирается по исполнению и таблицам приложения, а конкретное значение основной погрешности приводится в паспорте преобразователя. Эти сведения нужно получить из паспорта конкретного экземпляра.

Таким образом, JSON — документированный демонстрационный набор для тестирования импорта, проверки недостающих сведений и генерации, но не паспорт конкретного серийного экземпляра и не исходный второй товар от работодателя.
