# Product Copy AI

Локальный AI-помощник для подготовки черновиков карточек товаров B2B-магазина.

## Текущая версия

**v0.3.1** — локальная генерация через Ollama, модель по умолчанию `qwen2.5:14b`.

Исправлена обработка короткого SEO-описания: промпт задаёт структуру развёрнутого текста, генератор повторяет запрос с конкретными замечаниями валидатора, а при неудаче использует резервный текст, составленный из исходных данных без добавления неподтверждённых технических характеристик.

## Получить исходный код

В корне репозитория находится архив полного проекта:

`product_copy_ai_ollama_fix.tar.gz`

После `git pull` распакуйте его в корень репозитория:

```powershell
tar -xzf .\product_copy_ai_ollama_fix.tar.gz
Set-Location .\product_copy_ai
```

## Установка и запуск

Требуются Python 3.11+ и установленный Ollama.

```powershell
ollama pull qwen2.5:14b

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"

Copy-Item .env.example .env
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000/

Проверка тестов:

```powershell
python -m pytest -q
```

## Безопасность

Файл `.env`, виртуальные окружения и кэш исключены через `.gitignore`. Для локального Ollama API ключ не требуется.
