Реализовал локальный прототип на Python, FastAPI и Ollama. Сервис принимает данные через веб-форму или JSON, формирует структурированную B2B-карточку, проверяет SEO-ограничения и часть неподтверждённых технических утверждений. Дополнительно реализованы пакетная обработка, импорт CSV/XLSX, базовое извлечение текста из PDF, экспорт JSON/Markdown и сравнение локальных моделей.

Отдельно уделил внимание достоверности: технические характеристики переносятся из исходных данных, а спорные результаты возвращаются как черновики с замечаниями для контент-менеджера. В README описаны промпты, архитектурные решения, ограничения и запуск проекта.

В приложенном PDF задания я обнаружил полный пример только для манометра DM 02, хотя в тексте указаны два товара. Поэтому синтетические демонстрационные данные не выдаю за второй товар задания. Для дополнительной демонстрации второго типа прибора я также подготовил отдельный внешний пример ОВЕН ПД100И по официальному руководству производителя. Он явно помечен как внешний демонстрационный набор и не выдаётся за данные, предоставленные работодателем.
