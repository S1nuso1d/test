# Сценарий демонстрации Product Copy AI

Цель — за 3–5 минут показать путь от входных данных из каталога до проверяемого черновика карточки товара.

## Перед демонстрацией

1. Проверить наличие выбранных позиций в YML-фиде по инструкции `docs/PRODUCT_SOURCES.md`.
2. Установить зависимости, запустить Ollama и убедиться, что выбранная модель загружена.
3. Запустить приложение: `uvicorn app.main:app --reload`.
4. Открыть http://127.0.0.1:8000 и нажать «Проверить модель».
5. Использовать два входных товара:
   - `examples/product_oven_dts024_100p_v3_30_1.json` — термопреобразователь сопротивления;
   - `examples/product_oven_pd100_di4_0_185_0_5.json` — преобразователь давления.

## Порядок показа

### 1. Входные данные

Показать JSON-режим и разные категории приборов. Отдельно показать, что входные технические значения уже структурированы и не поручаются модели для повторного набора.

### 2. Генерация

Для одного товара показать SEO-заголовок, SEO-описание, поисковые запросы, список характеристик и коммерческий блок. Проверить длину заголовка и описания, количество запросов.

### 3. Контроль технических утверждений

Показать перенос характеристик из исходного JSON и замечания валидатора. Отдельно объяснить принятое решение по ПД100: значения штуцера и сопротивления нагрузки не переданы как однозначные, поскольку разные блоки карточки магазина расходятся.

### 4. Пакетный режим и экспорт

При наличии времени показать пакетную генерацию, экспорт JSON/Markdown, импорт CSV/XLSX. PDF-импорт демонстрировать только на текстовом PDF с простыми парами «параметр: значение»; отметить отсутствие OCR и необходимость ручной сверки.

### 5. Воспроизводимость

Показать README, скрипт `scripts/run_submission_check.py`, отчёт `examples/results/submission_report.md`, автоматические тесты и GitHub Actions.

## Что нельзя заявлять

- Что все галлюцинации полностью исключены.
- Что отсутствие замечаний автоматического аудита доказывает достоверность текста.
- Что PDF-парсер одинаково хорошо разбирает любые паспорта и сканы.
- Что формальный `quality_score` является вероятностью достоверности.
- Что SEO-запросы подтверждены реальной статистикой поискового спроса.

Главный тезис: приложение не просто создаёт текст — оно отдельно сохраняет исходные характеристики и показывает контент-менеджеру, какие места требуют внимания до публикации.
