# Источники и выбор товаров для тестового задания

## Основание выбора

В сообщении от работодателя кандидату разрешено выбрать любые два товара из товарного YML-фида СОЮЗ-ПРИБОР:

- https://www.souz-pribor.ru/yml/any/feed.xml

Для прототипа выбраны две разные категории приборов, чтобы проверить генерацию на неодинаковой технической структуре:

1. **ОВЕН ДТС024-100П.В3.30/1**, термопреобразователь сопротивления, код товара СОЮЗ-ПРИБОР 35481.
   - Карточка товара: https://www.souz-pribor.ru/product/dts024-100p-v3-30-1/
2. **ОВЕН ПД100-ДИ4,0-185-0,5**, преобразователь давления в полевом корпусе, код товара СОЮЗ-ПРИБОР 65403.
   - Карточка товара: https://www.souz-pribor.ru/product/pd100-di4-0-185-0-5/

Входные JSON находятся рядом с этим файлом:

- `examples/product_oven_dts024_100p_v3_30_1.json`
- `examples/product_oven_pd100_di4_0_185_0_5.json`

## ДТС024-100П.В3.30/1

Из карточки конкретной модификации взяты код товара 35481, НСХ 100П, длина кабельного вывода 1 м, отсутствие штуцера, общепромышленное исполнение и гарантия 12 месяцев. В таблице семейства ДТС для группы 50П/100П/Pt100 указан диапазон −50…+250 °C. Там же приведены общие конструктивные параметры семейства.

Класс допуска в таблице перечислен как А, В или С, но карточка не фиксирует один конкретный класс для выбранной модификации. Поэтому в JSON класс допуска не включён. Схема внутренних проводников указана как набор доступных вариантов (2-, 3- или 4-проводная), а не как выбранная конфигурация конкретного экземпляра.

Источник: https://www.souz-pribor.ru/product/dts024-100p-v3-30-1/

## ПД100-ДИ4,0-185-0,5

Из карточки товара взяты однозначно представленные параметры: максимальное давление 4,0 МПа, точность преобразования 0,5 % ВПИ (с оговоркой по диапазону), токовый выход 4…20 мА, питание 12…36 В, температурные диапазоны, IP65, перегрузочная способность, масса, габариты, межповерочный интервал, срок службы и конструкция полевого корпуса.

### Неоднозначности карточки магазина

На одной странице есть расхождения между кратким и подробным блоками:

- Присоединение к процессу: в кратком блоке указано G 1/4, в подробной таблице — M20×1,5 по ГОСТ 2405-88.
- Сопротивление нагрузки: в кратком описании указано 0…1800 Ом, в подробной таблице — 0…1,0 кОм в зависимости от напряжения питания.

Эти поля намеренно исключены из входного JSON. Не следует выбирать одно из противоречащих значений без уточнения у производителя или сверки с паспортом конкретного исполнения.

Источник: https://www.souz-pribor.ru/product/pd100-di4-0-185-0-5/

## Проверка попадания в YML-фид

Карточки товаров доступны на сайте СОЮЗ-ПРИБОР, однако в среде подготовки задания сам XML-фид не удалось загрузить напрямую. Перед финальной генерацией на компьютере, где доступен сайт, проверь наличие названий в скачанном фиде:

```powershell
$feedPath = Join-Path $env:TEMP "souz_pribor_feed.xml"
Invoke-WebRequest -Uri "https://www.souz-pribor.ru/yml/any/feed.xml" -OutFile $feedPath
Select-String -Path $feedPath -SimpleMatch -Pattern "ДТС024-100П.В3.30/1", "ПД100-ДИ4,0-185-0,5"
```

Ожидаются совпадения по обоим названиям. Если какой-либо товар в фиде не найден, его нельзя выдавать за выбранный из фида: замени JSON на позицию, которая присутствует в скачанном XML.

## Правило достоверности

Цена, наличие и срок поставки не включались в JSON: они могут изменяться и не нужны для формирования технической карточки. Спорные, конфигурационно-зависимые или невыбранные параметры не превращались в единственные характеристики. Перед публикацией результат LLM нужно сопоставить с актуальным паспортом/карточкой производителя и конкретной модификацией.
